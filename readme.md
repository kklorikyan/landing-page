## О проекте

Статический сайт-портфолио с главной страницей и отдельной страницей работ. Главная посвящена Кристине Клорикян: рассказывает о начале ее пути в веб-разработке, показывает блоки проектов и предлагает способы связи.

В оформлении используются розовые и кремовые градиенты, темные акценты, крупная типографика и декоративные рамки. Разметка написана на HTML, стили — на CSS; JavaScript, фреймворки, сборщик и пакетные зависимости отсутствуют.

## Страницы и разделы

| Страница | Содержимое |
| --- | --- |
| `index.html` | Представление автора, "Обо мне", карточки работ, "Почему я?", форма заявки и контакты |
| `pages/portfolio.html` | Отдельная подборка работ с изображениями и описаниями |

На главной доступны якорные переходы к разделам. Ссылка "все работы" открывает страницу портфолио, а меню внизу страницы повторяет основную навигацию.

## Быстрый старт

Установка зависимостей и сборка не нужны. Распакуйте архив и откройте терминал в папке проекта, где находится `index.html`.

### Через VS Code

1. Откройте папку проекта в VS Code.
2. Установите расширение **Live Server**, если оно еще не установлено.
3. Нажмите правой кнопкой на `index.html` и выберите **Open with Live Server**.

### Через Python 3

Запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

Откройте [главную страницу](http://localhost:8000/) или [портфолио](http://localhost:8000/pages/portfolio.html).

> Запускайте сайт через HTTP-сервер: часть ссылок и путей к ресурсам начинается с `/` и рассчитывает на корень сайта. При открытии HTML двойным кликом через `file://` они могут работать некорректно.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `index.html` | Разметка главной страницы |
| `pages/portfolio.html` | Разметка страницы портфолио |
| `styles/MainPage.css` | Стили главной страницы |
| `styles/Portfolio.css` | Стили страницы портфолио |
| `styles/useStyles.css` | Общие стили: контейнер, заголовки, карточки работ и подвал |
| `styles/reset.css` | Сброс базовых стилей браузера |
| `images/` | Логотип, иконки, изображения работ и фон портфолио |

CSS-классы преимущественно используют именование в стиле БЭМ. Общие элементы вынесены в `useStyles.css`, а оформление отдельных страниц — в соответствующие файлы стилей.

## Редактирование

| Что изменить | Где искать |
| --- | --- |
| Имя, описание автора, преимущества и контакты | `index.html` |
| Карточки на главной | Блок `#portfolio` в `index.html` |
| Работы на отдельной странице | Блок `.works` в `pages/portfolio.html` |
| Цвета, отступы и оформление главной | `styles/MainPage.css` |
| Оформление страницы работ | `styles/Portfolio.css` |
| Повторяющиеся элементы обеих страниц | `styles/useStyles.css` |
| Изображения и иконки | `images/` и соответствующие атрибуты `src` в HTML |

Контакты повторяются в нескольких блоках. При их замене обновите и основной раздел, и подвал каждой страницы.

## Текущее состояние

Проект содержит готовую статическую разметку и оформление, а часть контента и взаимодействий требует доработки:

- Вместо фотографии автора и реальных проектов используются заглушки.
- Форма содержит поля имени, телефона, email и вопроса, но обработчика `action="submit"` в архиве нет. Отправка заявок на почту не подключена.
- На странице портфолио остались имя и контакты Сергея Сулавко, а также ссылки на отсутствующий файл `images/logo.svg`. На главной используется `images/student_logo.svg`.
- Элементы "Подробнее" и "Загрузить еще" представлены визуально; логика раскрытия описаний и загрузки работ отсутствует.
- В CSS нет медиазапросов, а некоторые блоки имеют фиксированные размеры. Мобильная адаптация требует отдельной доработки.

## Размещение

Для публикации подойдет статический хостинг. Разместите `index.html`, папки `pages/`, `styles/` и `images/` в корне сайта, сохранив их структуру. Серверная сборка не требуется.

При публикации в подпапке нужно скорректировать пути, начинающиеся с `/`: сейчас они указывают на корень домена.
